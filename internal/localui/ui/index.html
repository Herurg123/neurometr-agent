      Что означают результаты?
      
Обнаружение GPU не доказывает работу ускорителя. Свободная видеопамять и наличие NPU пока не проверяются. Каталог моделей содержит данные, но ни одна модель автоматически не запускается: нет замеренных TPS, fit или подтверждённого backend.

      
Отчёты хранятся локально для текущего пользователя Windows. Экспорт производится только по вашему действию.
