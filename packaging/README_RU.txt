НЕЙРОМЕТР · Windows x64 · внутренний CI-комплект G4.1

СТАТУС: НЕ ДЛЯ ПУБЛИЧНОГО РАСПРОСТРАНЕНИЯ
Дистрибутив создан для автоматических тестов GitHub Actions.

Для будущего пользовательского сценария:
1. Распаковать архив в собственную папку.
2. Запустить Neurometr.exe двойным щелчком.
3. В открывшемся браузере нажать «Проверить компьютер».
4. Просмотреть результат и историю, экспортировать полный JSON вручную.

Никакой установки Go, Python, Node.js или llmfit не требуется.
Для быстрой диагностики Интернет не требуется. Модели не загружаются.

Приложение запускает защищённый сервер только на 127.0.0.1 со случайным
портом. История находится в личном каталоге Windows LOCALAPPDATA и
не шифруется. Доверенная граница не защищает от администратора и
вредоносного ПО под той же учётной записью.

В комплекте находится официальный llmfit v1.1.20 для будущего
опционального сценария. Он НЕ запускается автоматически. Наличие бинарника
не подтверждает работу GPU, inference или измеренные TPS.
Каталог моделей — metadata, а не результаты замеров.

Ограничения: GPU backend и NPU не испытывались; доступная выделенная VRAM
может оставаться неизвестной. Работа на компьютере владельца не
проверялась. Windows SmartScreen/Defender могут показывать предупреждения
для неподписанного дистрибутива; не отключайте системную защиту.

Доверенный bundled-каталог 2026.11.11.2, диагностический контракт 0.1.0.
release-manifest.json — инвентаризация размеров и SHA-256, не подпись.
Лицензия самого Agent пока не согласована; публичный выпуск заблокирован.
