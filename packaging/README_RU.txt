НЕЙРОМЕТР · Windows x64 · тестовая пользовательская сборка G4.2

СТАТУС: ТЕСТОВЫЙ БИНАРНЫЙ КОМПЛЕКТ, НЕ GITHUB RELEASE
Права владельца позволяют выдавать эту тестовую сборку через публичные
GitHub Actions artifacts ПОСЛЕ прохождения лицензионного gate на main.
Публикация возможна только при LEGAL_COMPLIANCE=PASS, OWNER_RISK_ACCEPTANCE=APPROVED
и успешном CI на main. Из PR/feature-веток ZIP не публикуется.
Условия: DISTRIBUTION_TERMS_RU.txt. Лицензия исходного кода Agent не назначена.

Порядок использования проверенной сборки:
1. Распаковать внутренний ZIP приложения в отдельную папку.
2. Запустить Neurometr.exe двойным щелчком.
3. В открывшемся браузере нажать «Проверить компьютер».
4. Просмотреть результат и историю, экспортировать JSON вручную.

Go, Python, Node.js и llmfit отдельно устанавливать не требуется.
Быстрая диагностика без Интернет-соединения; веса моделей не загружаются.
Перед запуском сверить SHA-256 ZIP с SHA256SUMS.txt и CI Summary.

Утилита открывает защищённый localhost сервер только на 127.0.0.1 со
случайным портом. История хранится в личном каталоге LOCALAPPDATA и не
шифруется; от процессов с теми же правами или администратора она не защищена.

В архив входит закреплённый официальный llmfit v1.1.20. Он НЕ запускается
автоматически. Обнаружение GPU/backend и прогноз TPS не означают успешной
работы модели. Веса GGUF и платные сервисы в архив не входят.

Ограничения: GPU/SYCL/NPU и запуск весов не тестировались; реальные ПК
пользователей не проверялись. Для неподписанного Neurometr.exe Windows
может показать SmartScreen/Defender; не отключайте системную защиту.

Bundled-каталог 2026.11.11.2, диагностический контракт 0.1.0.

THIRD_PARTY_NOTICES_RU.txt и LICENSES/.
