B. НЕЗАВИСИМАЯ АТТЕСТАЦИЯ ОФИЦИАЛЬНОГО EXE:
BINARY_PROVENANCE = NOT_VERIFIED. Подпись Authenticode подтверждает
действительную подпись проверяемого PE, но не устанавливает точный исходный
Rust compiled graph, активные features, исходный commit или web/dist.
Проверка Cargo tree / cargo metadata с locked dependencies и source LICENSE
составляет RECONSTRUCTED SOURCE INVENTORY, НЕ подтверждённый binary SBOM.
В проверенных сторонних текстах лицензий не установлено обязательства
получать независимую аттестацию конкретного подписанного EXE.
OWNER_RISK_ACCEPTANCE = APPROVED только для QA Actions artifacts:
G4_2_OWNER_RISK_ACCEPTANCE_RU.txt.
Отдельная независимая аттестация могла бы повысить supply-chain assurance,
но она НЕ подменяется строкой PASS и НЕ требуется как самостоятельный
юридический критерий после принятого владельцем риска.

C. CI ГРАНИЦЫ И РЕЗУЛЬТАТ:
tests/g4/audit_llmfit_windows_cli.py пересчитывает Cargo graph по
закреплённому llmfit HEAD, валидирует целевой inventory и собирает
оригинальные source notices. tests/g4/legal_compliance.py проверяет
обязательные уведомления/добавочные upstream LICENSE и доступность MPL
source по HTTPS/SHA и фиксирует LEGAL_COMPLIANCE=PASS либо FAIL.
Если проверка не пройдена, публикация BLOCKED; PR и feature-ветки не
публикуют ZIP независимо от результатов лицензирования.
Этот файл описывает механизм, а не сертификат происхождения EXE.
