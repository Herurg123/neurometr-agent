# Нейрометр: локальная утилита (Agent)

**Нейрометр** проверяет возможности компьютера для локального ИИ, строго разделяя обнаруженное, оценённое, измеренное и неизвестное. Локальная утилита разрабатывается на **Go**; первая поддерживаемая платформа — **Windows x64**.

Проект состоит из **двух связанных репозиториев**:

- [neurometr-agent](https://github.com/Herurg123/neurometr-agent) — локальная диагностика и экспорт JSON (этот репозиторий).
- [neurometr-web](https://github.com/Herurg123/neurometr-web) — статический сайт, просмотр диагностических файлов, канонические контракты и каталог моделей.

## Текущее состояние

В исходниках Agent реализованы нативный сбор Windows CPU/RAM/GPU, обработка частичных ошибок, **обычный офлайн-экспорт диагностического JSON v0.1.0** с проверенным комплектным каталогом и защищённый localhost-интерфейс с локальной историей. Для быстрой аппаратной диагностики не нужны обязательный llmfit или Интернет. Результаты проходят JSON Schema Draft 2020-12 и семантические проверки.

**Статус:** [A3.4 PR #7](https://github.com/Herurg123/neurometr-agent/pull/7) и [G4.1 PR #8](https://github.com/Herurg123/neurometr-agent/pull/8) **объединены в `main`**. В G4.1 внутренний Windows ZIP уже собран и проверен на облачном Windows runner; [CI #43260151749](https://github.com/Herurg123/neurometr-agent/actions/runs/43260151749) на merge commit `dbdd5984823be88eacc407046af12cd86e8d154f` — 3/3 PASS. Пользовательский компьютер, реальные модели и TPS не проверялись. Публичного GitHub Release нет.

## Текущая ограниченная разработка G4.2

**G4.2 (Draft PR, ещё не в `main`):** разрабатывается автоматическая передача проверенного Windows x64 ZIP и отдельного `SHA256SUMS.txt` через GitHub Actions **только для успешного push/ручного запуска на `main`**, с сохранением всей G4.1 проверки и 14-дневным хранением. Публичная доступность Actions artifact разрешена владельцем, но **сейчас фактическая выгрузка заблокирована** из-за незавершённого целевого аудита Rust-зависимостей и встроенных ресурсов подписанного llmfit EXE. Pull request и feature-ветки ZIP не публикуют. [Спецификация G4.2 и инструкция скачивания](docs/G4_2_ACTIONS_ARTIFACT.md).

- После завершения юридической проверки пользователь сможет открыть [GitHub Actions](https://github.com/Herurg123/neurometr-agent/actions/workflows/g4-1-private-zip.yml) → успешный запуск на `main` → **Artifacts** → скачать `neurometr-windows-x64-<commit>`. **Пока Summary показывает `BLOCKED`, скачиваемого ZIP нет.** GitHub оборачивает файлы в собственный ZIP; внутри должны быть ZIP Нейрометра и `SHA256SUMS.txt`.
- SHA-256 **внутреннего ZIP приложения** сверяется в PowerShell: `Get-FileHash -Algorithm SHA256 -LiteralPath '.\Neurometr-Windows-x64-<commit>.zip'`. Он должен совпасть с `SHA256SUMS.txt` и Actions Summary. При несовпадении не запускать файл.
- **Права и данные:** владелец разрешил только тестовый бинарный дистрибутив через Actions artifacts, не назначая OSS-лицензию исходникам. Контракты и bundled-каталог принадлежат проекту; происхождение Qwen и отсутствие весов документированы. **Остаточный блокер:** по проверенному Windows CI графу 215 normal/build Rust package/version (в том числе MPL-2.0, BSL-1.0, ISC и составные лицензии); из Cargo-lock источников теперь добавляются доступные оригинальные тексты LICENSE/NOTICE со своими SHA, но остаются crates без стандартных notice-файлов и не подтверждено соответствие точному подписанному EXE и содержимому npm web bundle. Полный список находится в `packaging/LLMFIT_WINDOWS_CLI_COMPONENTS_RU.txt`.

## Проверка исходников

Сборка и тесты выполняются преимущественно в **GitHub Actions**. Для разработчика с установленным Go на Windows x64 доступен тестовый CLI в текущем `main`:

~~~powershell
go run ./cmd/contractcheck -root .
go run ./cmd/catalogcheck -root .
go run ./cmd/diagnose -root . -output diagnostic.json
~~~

Это **не** инструкция владельцу устанавливать Go. Для конечного пользователя предусмотрен отдельный готовый ZIP, его выпуск пока не состоялся. Диагностический файл нужно считать приватным до проверки на персональные сведения.

## Ограничения и безопасность

- Факт обнаружения GPU/runtime не означает, что ускорение или модель работают.
- GPU/SYCL, NPU, измеренный TPS, реальные модели и оборудование владельца не испытывались.
- Удалённые обновления каталога с Ed25519 и пользовательская поставка пока не реализованы.
- В A3.4 защищённая локальная история опирается на проверку реального Windows ACL и личный каталог данных, но не создаёт шифрованное хранилище. Приложения под учётной записью того же пользователя и локальный администратор остаются за пределами этой границы защиты.
- Не передавать диагностический JSON на сервер автоматически; не выводить неизвестное как 0 или оценку как измерение.
